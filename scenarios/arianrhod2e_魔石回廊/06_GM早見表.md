# GM早見表（卓上用・印刷推奨）

---

## 魔石 効果一覧

| 魔石 | 効果（2倍） | 誰の位置で判定するか |
|------|-------------|---------------------|
| **増幅石〈アウグス〉** | レベル2倍 → 命中/回避/抵抗/打撃点に修正 | **行う側** |
| **貫穿石〈ペネトラ〉** | 受けるHPダメージ（最終値）2倍 | **受ける側** |
| **鉄殻石〈スクトゥム〉** | 防御力2倍 | **受ける側** |
| **護法石〈ムニート〉** | 魔法防御力2倍 | **受ける側** |
| **疾風石〈ケレル〉** | 移動力・行動値2倍 | **本人**（移動時／イニシアチブ時） |
| **反照石〈スペクルム〉** | エリア内の全魔石効果の倍率を**反転**（×2→×1/2） | エリア内すべて |
| **無銘石〈インフィニス〉** | 他の全台座の効果を、この台座のエリアに**中継** | エリア内すべて |

**レベル変動時の修正値 ＝（倍率適用後のレベル）−（元のレベル）**

| 元Lv | ×2 | ×4 | ×1/2 | ×1/4 |
|------|-----|-----|------|------|
| 4 | +4 | +12 | −2 | −3 |
| 6 | +6 | +18 | −3 | −4 |
| 8 | +8 | +24 | −4 | −6 |

- 増幅石でも**最大HP/MPは変化しない**
- 貫穿石は**回復量には影響しない**
- 反照石が偶数枚重なると**打ち消し合う**
- 増幅石がかかっていないキャラは、反照石エリアでもレベルは変化しない

---

## 計算順序（この順で処理する）

```
① レベル倍化（増幅石）      → 命中・打撃点・スキル効果値が確定
② 移動力・行動値倍化（疾風石）
③ 命中判定／回避判定        ← 魔石は命中率そのものを倍にしない
④ 打撃点を算出
⑤ 防御力／魔法防御力の倍化   → ④から減算
⑥ 被ダメージ倍化（貫穿石）   → ⑤の結果を最後に乗算
```

**端数はすべて切り上げ。**

## 重複

| 状況 | 処理 |
|------|------|
| 異なる種類 | 両方適用（上の順序で） |
| 同じ種類×2 | ×4 |
| 同じ種類×3以上 | ×4（上限） |
| 反照石が重なる | すべての倍率を逆数化（×2→×1/2、×4→×1/4） |
| 反照石×2 | 打ち消し合って効果なし |

## 台座の操作

| 行動 | コスト |
|------|--------|
| 魔石をセット／回収／入れ替え | **メジャーアクション**（台座に隣接、判定不要） |
| 台座を調べる | マイナーアクション |

- **1つの台座は1ラウンドに1回しか操作できない**
- 台座：防御力10／魔法防御力10／HP40（壊すと中の魔石は床に落ちる）
- **敵が台座を操作したラウンドは、その敵は攻撃できない**

## ボス〈デュプレクス〉クイックリファレンス

| | 通常（Lv8） | 増幅石エリア内（Lv16相当） |
|---|---|---|
| 双撃剣 | 命中+10／2D+16／至近 | 命中**+18**／**2D+24** |
| 倍律射 | 命中+9／2D+12／中距離 | 命中**+17**／**2D+20** |
| 回避 | +8 | **+16** |
| 抵抗 | +7 | **+15** |
| 防御力／魔法防御力 | 12／10 | **12／10**（《演算装甲》で不変） |
| HP | 160 | 160（変化なし） |

**行動指針（上から順に判定）**
1. 自分の足元にPC有利な魔石 → 隣の台座から回収（このラウンド攻撃なし）
2. 台座Ⅰの増幅石が抜けている → 挿し直しに向かう（PCが持ち去っていれば不可）
3. HP半分以下 → **《倍律解放》**（1ラウンドだけ全魔石効果を反転）
4. それ以外 → 最も近いPCへ攻撃。移動先は自分に有利なエリアを優先

**コア**：防御力15／魔法防御力15／HP80／自動命中／**魔石の影響を受けない**
　　　　デュプレクス健在の間、クリンナップにHP+10
