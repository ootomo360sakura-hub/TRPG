# アリアンロッドRPG 2E シナリオ『魔石回廊 ─ 二倍律の遺跡 ─』

倍率を操る古代遺跡を攻略するダンジョンハック・シナリオ。
**魔石**を拾い、戦闘マップ上の**台座**にセットすると、台座ごとに決められた
**反応エリア**の中にいる者すべてが「2倍」の効果を受ける。
複数の反応エリアが重なったスクエアでは効果が**重複**し、
戦場の一部だけが極端に危険/極端に有利な場所へと変わる。

「どこに立つか」「どの魔石をどの台座に挿すか」を毎ラウンド選び続ける、
戦術マップ運用が主役のシナリオになっている。

## 準備するもの

- スクエアマップ（方眼シート or オンセツール）。最大13×13スクエアを使う
- 魔石を表すコマ・カード8枚（全7種、うち鉄殻石は2個）（`06_GM早見表.md` の魔石カードを切って使える）
- 台座マーカー（マップ上に置く。最大4個）
- 反応エリアを示す枠（色違いのマーカーやテープ。**重なりが見えること**が重要）

## 卓の回し方（最短要約）

1. 魔石は「拾って持ち歩けるアイテム」。全7種・計8個がダンジョン内で手に入る
2. 台座は戦闘マップに固定で置かれている。**メジャーアクション**で1個セット/回収できる
3. セットした瞬間から、その台座の**反応エリア内の全キャラクター（敵味方問わず）**が効果を受ける
4. エリアが重なったスクエアでは効果が**乗算**で重複する（上限×4）
5. 敵も台座を使う。特にクライマックスのボスは開始時点で〈増幅石〉によりレベル2倍状態

詳細は [`02_魔石ギミック・ルール.md`](02_魔石ギミック・ルール.md) を参照。
