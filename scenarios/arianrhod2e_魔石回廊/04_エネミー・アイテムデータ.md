# エネミー＆アイテムデータ

本シナリオ用に作成した独自データ。想定レベル4のPC4人を基準に調整してある。
人数・レベルによる調整は `01_シナリオ本編.md` の「6. 難易度調整」を参照。

戦利品は百分率ロール（1D100相当の2D10×10＋1D10、またはGMの好きな方法）で決定する。

## エネミー

### ■ スケルトン・ランナー　Lv3　／　アンデッド

シーン4（マップA）に3体。走る姿勢のまま朽ちた骸骨。反応エリアの中では異常に速い。

```
知能：なし　　知覚：暗視　　反応：敵対的　　属性：闇
移動力：6　　行動値：10

攻撃方法        命中   打撃点   射程
錆びた曲刀      +5     2D+6     至近

回避：+5　防御力：4　魔法防御力：2　HP：26　MP：0　抵抗：+2
```

**スキル**
- **《疾走》**（パッシブ）：ムーブアクションで移動した場合、そのラウンドの命中判定に+1。
- **《骨の身体》**（パッシブ）：打撃属性の攻撃に対し、防御力+2。

**戦利品**：1〜60／なし　61〜90／古びた曲刀（150G）　91〜00／魔晶石（300G）
**経験点**：20

> **GMメモ**：3体のうちH4の1体だけが台座αの反応エリア外にいる。
> 行動値10と、エリア内の20（疾風石で2倍）の差を実際に見せること。
> 「エリアに入ると速くなる」を体で覚えさせるための配置である。

### ■ ゲム・イーター　Lv4　／　魔獣

シーン6に2体。魔石を主食にする四足の魔獣。喉に半消化の魔石が透けて見える。

```
知能：動物並み　知覚：魔法感知　反応：敵対的　属性：地
移動力：7　　行動値：11

攻撃方法        命中   打撃点   射程
喰らいつき      +7     2D+8     至近

回避：+6　防御力：5　魔法防御力：6　HP：38　MP：12　抵抗：+4
```

**スキル**
- **《魔石喰い》**（メジャーアクション）：隣接する台座から魔石を1個奪い、体内に取り込む。
  または隣接するキャラクターの所持する魔石1個を狙う（対象は【器用度】判定・目標値13で抵抗）。
  取り込まれた魔石は、この個体を倒すと取り出せる。
- **《魔力捕食》**（パッシブ）：魔法によるダメージを受けるたび、HPを3回復する。

**戦利品**：1〜40／なし　41〜80／魔獣の牙（250G）　81〜00／濃縮魔晶石（600G）
**経験点**：30

> 1体は体内に **〈貫穿石〉** を保持している（撃破で確定入手）。
> もう1体は魔晶石を数個飲み込んでいるだけ。

### ■ ソケット・ゴーレム　Lv6　／　魔法生物　【シーン8のリーダー】

胸に台座と同じ円盤が埋め込まれた石人形。ドゥプレクス派の「歩く実験台」。

```
知能：なし　　知覚：魔法感知　反応：敵対的　属性：無
移動力：5　　行動値：8

攻撃方法        命中   打撃点   射程
岩塊の拳        +8     2D+13    至近
薙ぎ払い        +7     2D+9     至近（範囲）

回避：+3　防御力：9　魔法防御力：5　HP：85　MP：0　抵抗：+5
```

**スキル**
- **《胸の台座》**（パッシブ）：この個体の胸には**〈鉄殻石〉が1個セットされている**
  （このため上記の防御力9には既に2倍が反映されている＝素の防御力は5）。
  隣接するキャラクターは、**【筋力】判定（目標値15）＋メジャーアクション**で
  これを引き抜ける。引き抜かれると**防御力が9→5に低下**する。
- **《薙ぎ払い》**（メジャーアクション）：射程内の敵2体を対象に、上記「薙ぎ払い」で攻撃する。
- **《鈍重》**（パッシブ）：ムーブアクションで移動した場合、そのラウンドの回避判定に−2。

**戦利品**：1〜50／魔石の欠片（400G）　51〜90／硬化石材（800G）
　　　　　　91〜00／ドゥプレクス派の刻印板（1,500G・名誉点+5）
**経験点**：60

> **GMメモ**：開始位置G5は台座βと台座γの重複ゾーン。
> PCが台座γに〈貫穿石〉を挿せば、この重複ゾーンはゴーレムにとって死地になる。
> ゴーレムは《鈍重》のせいで逃げるのが下手であり、
> 「重い敵をエリアに閉じ込める」という戦術の教材として機能する。

### ■ 倍律の守護者〈デュプレクス〉　Lv8　／　魔法生物　【ボス】

コアを守るためだけに300年間立ち続けた鎧。中身は空だが、声だけが残っている。

```
知能：人間並み　知覚：魔法感知　反応：敵対的　属性：無
移動力：6　　行動値：12

攻撃方法        命中   打撃点   射程
双撃剣          +10    2D+16    至近
倍律射          +9     2D+12    中距離

回避：+8　防御力：12　魔法防御力：10　HP：160　MP：40　抵抗：+7
```

**スキル**
- **《演算装甲》**（パッシブ）：**魔石による効果を受けても、防御力と魔法防御力だけは
  2倍にならない**（コアの演算に組み込まれているため）。逆に**半減もしない**。
- **《排除機動》**（ムーブアクション）：移動の際、**キャラクターのいるスクエアを通過できる**。
  台座への到達を妨害しにくい。
- **《台座操作》**（メジャーアクション）：隣接する台座の魔石を回収／セットする。
  PCと同じルール。**この行動をしたラウンドは攻撃できない。**
- **《倍律解放》**（セットアッププロセス／HPが半分以下・1シナリオに1回）：
  このラウンドの間、**マップ上のすべての魔石効果の倍率が反転する**（×2→×1/2、×4→×1/4）。
  PCが築いた陣形が丸ごと裏返る。効果はこのラウンド終了時に元へ戻る。

**戦利品**：確定／**〈増幅石〉**（台座Ⅰから回収していない場合はここで入手）
　　　　　　1〜60／守護者の鎧片（2,000G）　61〜00／二倍律の術式書（5,000G・名誉点+10）
**経験点**：120

> **増幅石エリア内での数値（レベル16相当）**
> 命中：双撃剣+18／倍律射+17　　打撃点：2D+24／2D+20
> 回避：+16　抵抗：+15　　※防御力・魔法防御力は《演算装甲》により12／10のまま
> ※HP・MPの最大値は変化しない

## オブジェクトデータ

### ■ 台座（ソケット）

```
防御力：10　魔法防御力：10　HP：40　回避判定：なし（自動命中）
```
- 破壊されると反応エリアは即座に消滅する。中の魔石は無傷でそのスクエアに落ちる。
- 修復はできない（このシナリオ中は）。

### ■ 二倍律のコア

```
防御力：15　魔法防御力：15　HP：80　回避判定：なし（自動命中）
```
- **魔石の効果を一切受けない**（静域にあり、かつ効果の発生源そのものであるため）。
- デュプレクスが健在の間、**クリンナッププロセスにHPを10回復**する。
- HPが0になると破壊され、シナリオはクライマックス終了へ移行する。
