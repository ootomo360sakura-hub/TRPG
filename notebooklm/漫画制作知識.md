# コマ割りの基礎

## 読み方向
- 日本の漫画は **右→左、上→下** に読む(右開き)
- ページの入口は**右上**、出口は**左下**
- 4コマ・Web縦読み(webtoon)は例外で、上→下の一直線

## コマの大きさと時間
- **大きいコマ = 時間がゆっくり流れる/重要**
- **小さいコマ = テンポが速い/経過描写**
- コマの大小の差(緩急)がそのまま演出になる

## ワク線とタチキリ
- **基本ワク線**: 太さ2〜3px相当の黒枠
- **タチキリ(裁ち切り)**: コマを紙の端まで伸ばす。開放感・迫力が出る
- **ワク線なし**: 回想・心象風景の表現に使う
- **斜めのワク線**: スピード感・動揺の表現

## 吹き出し(フキダシ)の種類
| 種類 | 形 | 用途 |
|------|-----|------|
| 通常 | 楕円 | 通常の会話 |
| 叫び | ギザギザ(爆発形) | 大声・驚き |
| 心の声 | 雲形/点線 | モノローグ |
| 電話・機械 | カクカク+稲妻しっぽ | 電子音声 |
| ナレーション | 四角 | 状況説明 |

- しっぽ(テール)は**話者の口元**に向ける
- セリフは**縦書き**。1行はおおむね7〜12文字で改行
- 読み順と同じく、吹き出しも右→左の順に配置する

## ページの「引き」
- 各ページの最終コマ(左下)には「次を読みたくなる要素」を置く
- 質問・危機・新事実の提示が定番

# 吹き出しとセリフの作法

## セリフの文字組み
- 縦書きが基本。フォントは**アンチゴチ**(かな=アンチック体、漢字=ゴシック体)が伝統
- 1つの吹き出しに入れるセリフは**20〜30文字以内**が読みやすい
- 長台詞は吹き出しを2つに割る(「…」でつなぐ)

## 縦書きで形が変わる文字
| 横書き | 縦書き |
|--------|--------|
| ー(長音) | 縦棒に回転 |
| 「 」 | ﹁ ﹂ |
| 、。 | 文字の右上に寄せる |
| !? | 縦中横(2文字を横に並べる) |

## 配置のルール
1. 吹き出しは読み順(右上→左下)に沿って置く
2. キャラクターの**顔を隠さない**
3. しっぽは話者の口元へ。コマ外の話者には「コマ外しっぽ」
4. 吹き出しがコマ線をまたぐのは許容(むしろ抜け感が出る)

## 効果音(オノマトペ)
- 手描き文字で絵の一部として描く
- ドーン(衝撃)、ゴゴゴ(不穏)、シーン(静寂)など
- 入れすぎると絵が死ぬ。1コマ1〜2個まで
