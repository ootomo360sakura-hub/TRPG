# コマ割りの基礎

## 読み方向
- 日本の漫画は **右→左、上→下** に読む(右開き)
- ページの入口は**右上**、出口は**左下**
- 4コマ・Web縦読み(webtoon)は例外で、上→下の一直線

## コマの大きさと時間
- **大きいコマ = 時間がゆっくり流れる/重要**
- **小さいコマ = テンポが速い/経過描写**
- コマの大小の差(緩急)がそのまま演出になる

## ワク線とタチキリ
- **基本ワク線**: 太さ2〜3px相当の黒枠
- **タチキリ(裁ち切り)**: コマを紙の端まで伸ばす。開放感・迫力が出る
- **ワク線なし**: 回想・心象風景の表現に使う
- **斜めのワク線**: スピード感・動揺の表現

## 吹き出し(フキダシ)の種類
| 種類 | 形 | 用途 |
|------|-----|------|
| 通常 | 楕円 | 通常の会話 |
| 叫び | ギザギザ(爆発形) | 大声・驚き |
| 心の声 | 雲形/点線 | モノローグ |
| 電話・機械 | カクカク+稲妻しっぽ | 電子音声 |
| ナレーション | 四角 | 状況説明 |

- しっぽ(テール)は**話者の口元**に向ける
- セリフは**縦書き**。1行はおおむね7〜12文字で改行
- 読み順と同じく、吹き出しも右→左の順に配置する

## ページの「引き」
- 各ページの最終コマ(左下)には「次を読みたくなる要素」を置く
- 質問・危機・新事実の提示が定番
