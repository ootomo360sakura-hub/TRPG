## Drive とリポジトリの役割分担

| | Googleドライブ | GitHub(このリポジトリ) |
|---|---|---|
| 主な役割 | 閲覧・共有・素材置き場 | コードとバージョン管理 |
| テキスト資料 | **読み書きの正**(Googleドキュメント) | `docs/` にMarkdownの写しを置く |
| 画像・音声素材 | ここに集約 | 置かない(容量とバイナリ差分のため) |
| ソースコード | 置かない | ここで管理 |

テキスト資料は両方に置くが、**内容が食い違った場合はDrive側を正とする**。

## 資料を追加するときの手順(Claude Code向け)

1. 上表から対象フォルダIDを選ぶ。
2. Google Driveコネクタの `create_file` で、`parentId` にそのIDを指定して作成する。
   - `contentMimeType: text/markdown` にすると、Markdownが自動でGoogleドキュメントに変換される。
3. リポジトリ側にも同じ内容を `docs/` にMarkdownで置き、コミットする。
4. 新しいフォルダを作った場合は、このファイルのフォルダID一覧に追記する。

## 注意

- Drive上のファイルを**上書き・削除する場合は必ず事前に確認を取る**。Googleドキュメントは変更履歴から復元できるが、削除は確認なしに行わない。
- 既存資料を書き換える場合は、Googleドキュメントの「変更履歴に名前を付ける」で書き換え前の状態に日時入りの名前を付けてから編集する(バックアップの代わり)。
